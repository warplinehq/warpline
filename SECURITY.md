# Security

Warpline's core claim is safety: side-effect-declaring plugins do not run
without explicit human approval, at every autonomy level. If you find a way
to defeat that — an approval-gate bypass, a side-effect that escapes
declaration, a path traversal in the home/state resolution — we want to know
privately first.

**Report privately:** use GitHub's "Report a vulnerability" (Security tab →
Advisories) on this repository, or email <adnan@kernel.associates>.

Please do not open public issues for suspected vulnerabilities. You'll get an
acknowledgement within a few days; fixes ship as patch releases with credit
unless you prefer otherwise.
